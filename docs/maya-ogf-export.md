# Экспорт скелетного OGF из Maya

В `File → Export Selection` или `Export All` выберите **IX-Ray skeletal OGF export**.
Плагин записывает OGF v4 непосредственно из сцены, без промежуточного `.object`.

## Подготовка

- Один меш с одним skinCluster и одним корнем скелета, до 64 костей.
- Меш должен быть триангулирован, иметь UV и назначенные материалы.
- Трансформации меша и его родительских групп должны быть единичными: используйте
  подготовленный для экспорта меш с замороженными трансформациями.
- Как и для существующего экспорта skeletal `.object`, все родительские кости
  должны присутствовать среди influences skinCluster. Имена костей без namespace
  должны быть уникальными.
- Материалы должны содержать игровой shader и путь к текстуре. Используйте
  материал IX-Ray для явного задания этих значений.

Скелет временно переводится в bind pose для чтения геометрии. После экспорта
плагин восстанавливает сохранённые трансформации суставов.

## Настройки

**Maya normals** сохраняет нормали углов треугольников Maya, включая custom normals
и жёсткие границы. Это режим по умолчанию.

**SDK SoC** пересчитывает нормали по группам сглаживания, полученным из soft/hard
edges Maya. Как в SDK для Maya-групп, нормали усредняются у общей вершины только
для одинаковых номеров групп; отдельные жёсткие грани не сглаживаются.

**SDK CS/CoP** пересчитывает нормали по связанным веерам граней вокруг вершины,
переходя только через soft edges. Hard edges и границы меша разделяют веера.

Выбор сглаживания не выбирает версию игры. Совместимость весов задаётся отдельно:

- **2 (SoC / CS / CoP)** — не более двух костей на вершину, совместимый с SoC
  формат вершин.
- **4 (CS / CoP / IX-Ray)** — не более четырёх костей на вершину.

При превышении выбранного лимита остаются самые сильные веса, затем их сумма
нормализуется. Режим сглаживания и лимит весов сохраняются между сеансами Maya.

**OMF references** — список путей относительно `gamedata/meshes`, без расширения
`.omf`, через запятую, например `weapons/ak74,actors/shared`.
Указанные OMF должны существовать в игре и соответствовать экспортируемому скелету.
При заполнении поля создаётся анимированная скелетная модель со ссылками на OMF;
без ссылок — скелетная модель без анимаций. Анимации из timeline в OGF не включаются.

## Содержимое файла

Экспортируются геометрия, UV, нормали, касательные, материалы, веса и иерархия костей,
bind pose, формы коллизий и физические параметры костей, доступные существующему
экспортёру Maya. Двусторонние материалы получают обратные треугольники.
Части разделяются по материалам и при достижении предела 16-битных индексов.

Используется обычная скелетная геометрия без progressive mesh / LOD. Расчёт
касательных выполняется экспортёром; побайтовое совпадение с MeshMender SDK не
предполагается. Статические модели этим новым пунктом не экспортируются.

## Проверка сборки

Для сборки автономного теста конвертера включите `IXR_BUILD_MAYA_OGF_TESTS=ON`
в конфигурации CMake с плагинами. Соберите `MayaOgfExportTests` и запустите его,
передав путь к тестовому `.ogf` в рабочем каталоге. Тест перезаписывает этот файл.

Тест проверяет обратное чтение OGF через PCore, три режима нормалей, 2/4 веса,
материалы, двусторонность, разбиение больших мешей, ссылки на OMF и отказ на
некорректных данных. Проверка конвертера не заменяет проверку окна настроек и
экспорта пользовательской сцены в Maya и загрузки модели в игре.
