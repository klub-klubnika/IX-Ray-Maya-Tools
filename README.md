# IX-Ray Maya Tools

Плагин Maya для импорта и экспорта ресурсов X-Ray Engine, включая OGF-модели и анимации.

## Что потребуется

- Windows x64;
- Visual Studio 2022 с компонентом **Desktop development with C++**;
- CMake 3.26 или новее;
- установленная Autodesk Maya 2024, 2025, 2026 или 2027;
- подключение к интернету при первой настройке: CMake загрузит SDK выбранных версий Maya.

## Быстрый старт

1. Клонируйте репозиторий и откройте его папку.
2. Запустите `Generate-VS2022.bat`.
3. После завершения откройте `build-vs2022\IXRayMayaTools.sln` в Visual Studio 2022.
4. В верхней панели Visual Studio выберите конфигурацию `Release` и платформу `x64`.
5. В обозревателе решений выберите нужный проект и выполните **Build**:
   - `MayaTools_2024` для Maya 2024;
   - `MayaTools_2025` для Maya 2025;
   - `MayaTools_2026` для Maya 2026;
   - `MayaTools_2027` для Maya 2027.

## Создание решения вручную

Если скрипт не запускается, откройте командную строку в папке проекта и выполните:

```bat
cmake --preset vs2022
```

Решение появится по адресу:

```text
build-vs2022\IXRayMayaTools.sln
```

## Сборка из командной строки

Например, для Maya 2024:

```bat
cmake --build build-vs2022 --config Release --target MayaTools_2024
```

Готовый плагин будет здесь:

```text
build-vs2022\Maya\Release\ixray_maya_tools_2024.mll
```

Для другой версии Maya замените `2024` на `2025`, `2026` или `2027`.

## Подключение плагина в Maya

1. Откройте **Windows → Settings/Preferences → Plug-in Manager**.
2. Нажмите **Browse** и выберите собранный файл `.mll`.
3. Включите **Loaded**. Включите **Auto load**, если плагин должен загружаться при каждом запуске Maya.

## Структура проекта

- `Maya/` — исходники плагина и скрипты Maya;
- `PCore/` — библиотека форматов X-Ray Engine, необходимая плагину;
- `tests/` — регрессионный тест экспорта OGF;
- `docs/` — техническая документация экспорта OGF.

## Устранение проблем

**Не найдены файлы `maya/M*.h`**

Повторно запустите `Generate-VS2022.bat`. Он загрузит SDK Maya и обновит проект Visual Studio.

**Открыт старый `.sln`**

Удалите папку `build-vs2022` и снова запустите `Generate-VS2022.bat`.

**Плагин не загружается в Maya**

Проверьте, что номер версии в имени `.mll` совпадает с установленной версией Maya.
